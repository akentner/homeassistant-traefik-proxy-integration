# Traefik Proxy 1.0.1

A small documentation and licensing release. **No action required**; entities,
devices and behaviour are unchanged.

## What changed

- **Licence notice for the brand images now ships with the integration.** The
  icon and logo are derived from `traefik/traefik` (MIT). The copyright notice
  and MIT text are in `custom_components/traefik_proxy/brand/LICENSE.md`, so
  HACS installs carry them (HACS ships only `custom_components/`).
- **Trademark section updated** in the README and `docs/BRAND.md`: it records
  the review of 2026-11-20 and notes that the same artwork is part of the
  Traefik Labs press kit. Traefik is a trademark of Traefik Labs; this project
  is independent.

Full list of changes: [CHANGELOG](https://github.com/akentner/homeassistant-traefik-proxy-integration/blob/v1.0.1/CHANGELOG.md#101---2026-11-20).
