### Pagination (D-07 termination rule)

`per_page=100` (`PAGE_SIZE`), query `?per_page=100&page=N`. Observed `X-Next-Page` values, identical in both generations:

| Endpoint | Page 1 | Page 2 |
|---|---|---|
| `/api/http/routers` (129 items) | `2` | `1` (last page) |
| `/api/http/services` (8 items) | `1` (last page) | – |
| `/api/http/middlewares` (2 items) | `1` (last page) | – |

**Rule for the 04-04 client:** the last page sends `X-Next-Page: 1`, not an absent header. Stop when the header is missing, not an integer, or `<= current page`; keep a hard page cap as loop guard. Router items across pages (100 + 29) equal `len(rawdata.routers)` (129), and the list endpoints include `@internal` items the same way rawdata does.

- **Files modified:** tests/traefik/capture.py, tests/test_fixture_redaction.py
- **Commit:** 14d3cf5, e66b8dc

## Worker Decisions

- whoami pinned as `traefik/whoami:v1.12.0@sha256:...`. Reason: the version label is `1.12.0` and the `v1.12.0` tag resolves to the same digest as `latest`. Alternative: pin `latest@sha256` (less readable).
- `HARNESS_PASSWORD = "harness-only-not-a-secret"`, bcrypt hash with `$2a$` prefix, cost 10. Reason: `$2a$` is the prefix Go's bcrypt (Traefik) accepts everywhere. Alternative: `$2b$` (python default, untested with Traefik).
- Shared static config through a YAML anchor `x-traefik`. Reason: both generations get identical flags and mounts by construction. Alternative: duplicated command lists.
- Capture brings both generations up in one compose run and redacts after both captures with one Redactor. Reason: the same docker IP maps to the same documentation IP in both generations. Alternative: sequential up/down per generation.
- 12- and 64-hex container-ID rule requires at least one letter and one digit. Reason: keeps plain numbers (e.g. certificate serials) and words intact. Alternative: match any hex run.
- Certificate fingerprints and `name` in certificates.json are zeroed by the container-ID rule; kept that way. Reason: throwaway cert, makes the file stable across cert regeneration. Alternative: exempt certificates.json (Phase 6 may want distinct names when there is more than one cert).
- Throwaway cert: ECDSA P-256, valid 90 days from generation, created only when absent. Reason: fast, LE-like lifetime. Note: `certificates.json` `notAfter` changes when the git-ignored cert is regenerated on another machine; Phase 6 tests must freeze time.
- Stale `pages/*.json` are deleted before writing a generation. Reason: the directory always matches the latest capture. Alternative: leave old pages.
- Readiness also waits for `bulk-119@file` and `secure@file`. Reason: guarantees the paginated set is complete before capture.
- Test-side IP/hostname regexes are written independently of capture.py (only credentials come from the script). Reason: a bug in the redactor regex cannot hide itself in the guard.
