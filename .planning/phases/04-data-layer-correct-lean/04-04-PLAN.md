<objective>
Prove the new data path end to end and move every consumer onto it: real fixture pages -> models -> client read API -> snapshot coordinator -> existing entities. After this plan the coordinator publishes a typed, frozen TraefikSnapshot with precomputed aggregates and `always_update=False`, and no consumer touches raw API dicts.

Purpose: DATA-06 (snapshot + aggregates + always_update=False), DATA-01 consumer half (platforms never inspect raw dicts), and the pagination half of DATA-02 (no truncation at 100). The client keeps the list endpoints in this plan (they are the existing transport, now paginated and typed); 04-06 puts `/api/rawdata` in front of them and they become the D-07 fallback without architectural change.
Output: client read API, rewritten coordinator, minimally adapted platforms/cert coordinator/reload handler (D-17), shared test helpers, pagination edge tests.

Scope guards: keep the legacy client methods and the existing constructor (`api_key=`) untouched (04-05 replaces them); keep `reload_routers`, the reload service and button working (D-06); do not touch tests/test_verify_ssl.py, tests/test_reconfigure.py, tests/test_config_flow.py or tests/test_api.py (their legacy stubs still serve version, entrypoints and the three list endpoints, which is exactly what the new path requests).
</objective>
