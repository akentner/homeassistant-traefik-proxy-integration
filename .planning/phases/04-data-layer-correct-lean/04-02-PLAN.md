<objective>
Replace the "runtime_data is the main coordinator with a monkey-attached cert coordinator" shape with a typed `TraefikRuntimeData(client, coordinator, cert_coordinator)` container (DATA-05, audit A-11), keeping the current raw-dict coordinator payload untouched so this plan is independent of the fixture capture running in parallel (04-01) and of the models plan that follows it (04-03).

Purpose: every later plan (and Phase 5-7) reads runtime state through one typed object; the client gets a single owner so the options listener can never leave the coordinator on a stale client (risks 4 and 5 of 04-PATTERNS.md: setup order and client drift).
Output: new data.py; minimal, mechanical edits in coordinator.py, __init__.py, entity.py, the three platforms and cert_coordinator.py; test wiring updated.

Scope guard: coordinator.data stays the existing dict in this plan (04-04 swaps it to TraefikSnapshot). Do not touch tests/conftest.py (04-03 adds the fixture loader and 04-04 the snapshot helpers there).
</objective>
