<objective>
Close gap CR-01 (BLOCKER, M26): the two TLS certificate entity classes must re-render on the cert coordinator's own notifications, so a cert cycle that finds a certificate inside the warning window, and a `tls_warn_days` change, reach the HA state machine again.

Purpose: Phase 4 set `always_update=False` on the main coordinator (D-13, DATA-06, correct and kept). The cert entities were still `CoordinatorEntity` listeners of the main coordinator and only read the cert coordinator inside their properties, so they lost the incidental 15 s re-render they depended on. This breaks the phase goal clause "user-visible entities keep working unchanged" (ROADMAP Phase 4 SC5) and the project's core value ("which TLS certificates are expiring soon"). Requirement: DATA-06 (the regression came with it) plus phase-goal SC5.
